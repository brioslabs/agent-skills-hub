## When to Use

- Building visually striking, responsive web application interfaces.
- Designing component systems with modern CSS (custom properties, glassmorphism, flexbox, CSS grid).
- Implementing accessible and semantic HTML5 layout structures.
- Adding subtle micro-interactions and smooth UI transitions.

## Critical Patterns

1. **Custom Properties & Design Tokens**: Define color palettes, typography, spacing, and elevation in standard CSS variables.
2. **Semantic HTML**: Use explicit elements (`header`, `main`, `nav`, `section`, `article`, `footer`, `button`).
3. **No Unstyled Components**: Every interactive component must feature hover, active, and focus states.
4. **Responsive Layouts**: Utilize CSS Grid and Flexbox for liquid, mobile-first responsive design.
